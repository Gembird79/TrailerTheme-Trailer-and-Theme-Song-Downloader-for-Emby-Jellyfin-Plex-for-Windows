(Installer-Icon entspricht dem App-Icon.)

---

## Was kann TrailerTheme?

| Bereich | Beschreibung |
|---------|----------------|
| **Scanner** | Film-/Serienordner scannen, passende Trailer finden und herunterladen |
| **Theme-Songs** | Intro- und Titelsongs suchen und als MP3 speichern |
| **Verifizierung** | Downloads prüfen, bestätigen oder ersetzen |
| **Pro-Version** | Free-Testkontingent, danach Lifetime- oder Jahreslizenz |
| **Einstellungen** | Qualität, Sprache, Browser/Cookies, Hilfsprogramme aktualisieren |

## English summary

TrailerTheme helps you download **trailers** and **theme songs** for Emby/Jellyfin libraries on Windows.  
This repo publishes **installers and screenshots only** (no source code).  
See [Releases](https://github.com/Gembird79/TrailerTheme-Releases/releases) for downloads.
